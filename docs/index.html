Screen recording to markdown

“As you can see here…”

A transcript keeps that sentence and loses the screen it points at. FrameProof keeps both. It samples the recording, drops the repeat frames, has a vision model read the distinct ones as tables, text and code, and merges them with the speech on one timeline, in one markdown file.

The bench below is computed, not replayed. It runs the tool's duplicate check, ported line for line to JavaScript, on a two-minute example recording. Point it at a recording of yours and it does the same; the file never leaves this tab.

What the hash sees

9 × 8 grey pixels
64 bits

Each bit says whether a pixel is brighter than its right-hand neighbour. Bits that differ from the last kept frame are marked. The script keeps a frame only when at least --threshold bits differ.

What to check before you trust it

    

      
Numbers read off a chart are estimates
When a chart prints no values, the model reads heights off pixels. Those tables carry the line > Values estimated from the chart; verify. and the synthesis step is told never to drop it. --embed-images puts each frame next to its table so you can spot-check.

      
Kept frames leave your machine
Whisper runs locally. The frames that survive the duplicate check are sent to the Anthropic API to be read, one call per frame, which is also where nearly all the cost sits.

      
App recordings need masking by hand
A clock or ticker changes on every sample. extract_frames.py has no mask option; SKILL.md gives a short snippet that blanks the regions you list before hashing.

      
A missing stream is declared, not hidden
If transcription or the vision pass was skipped or blocked, the skill puts a callout at the top of the document saying what is absent. Frames that fail are listed in failed_frames.json and rerun with --retry-failed.

      
Timestamps mark a window, not an instant
Each frame is labelled with the start of its sampling window and taken from near the middle of it, so a label can sit up to half an interval before the frame.

      
Long recordings: tune on a slice first
Past about 90 minutes, cut ten minutes with ffmpeg -ss 0 -t 600, settle the interval and threshold there, then run the whole file.
