What was said and what was on screen, in one markdown file.

A transcript-only converter drops the video track. FrameProof samples the screen, keeps only the distinct frames, reads them with a vision model and merges the result with the transcript by timestamp. Set up a recording below and watch what survives.

The call counts are a rough guide built from the figures in SKILL.md: a typical 40-minute talk keeps 20 to 40 distinct frames, and one 10-minute terminal recording kept 44 frames unmasked while showing only 4 distinct screens. The vision pass runs once per kept frame, so that count is where nearly all the cost sits.
